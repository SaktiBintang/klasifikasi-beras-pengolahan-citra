Praktikum ini menerapkan operasi dasar pengolahan citra menggunakan Python, OpenCV, NumPy, dan Matplotlib di Google Colab.

### Materi yang Diterapkan

1. Operasi Aras Piksel
   - Brightness
   - Contrast
   - Negative Image
   - Thresholding

2. Operasi Aritmetika
   - Addition
   - Subtraction
   - Multiplication
   - Division

3. Operasi Boolean
   - AND
   - OR
   - NOT
   - XOR

4. Masking

5. Operasi Geometri
   - Translation
   - Rotation
   - Scaling
   - Reflection
   - Shearing
